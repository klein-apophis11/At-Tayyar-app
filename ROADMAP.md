# 🗺️ At-Tayyar Accessibility Development Roadmap

This document tracking layout outlines the future feature sprints intended to expand the utility, accessibility, and modern interface layout framework of **At-Tayyar** for believers managing mobility limitations.

---

## ⚡ Sprint 1: Zero-Touch Navigation & Input Panels
- [ ] **Voice-Activated Prayer Commands**: Integrate an offline voice parsing engine (e.g., `Vosk`) to support verbal inputs like *"Next Step"*, *"Play Audio"*, or *"Repeat Ayat"*.
- [ ] **Dwell-Time Clicking Layer**: Build an automated timer overlay for eye-tracking/head-pointer devices where hovering over a structural target for 2 seconds registers a native click.
- [ ] **Single-Switch Access Architecture**: Implement a configuration mode allowing full application step cycling using a single hardware button/proxy switch loop.

## 🎨 Sprint 2: High-Utility Interface Panels
- [ ] **Accessible High-Contrast Profiles**: Deploy global toggle states for absolute monochrome, low-vision scaling, and custom oversized boundary targets.
- [ ] **Oversized Assistive Tasbih Counter Window**: Add a companion panel supporting large-format tap tracking or spacebar shortcut triggers with distinct auditory increment tones.

## 🔊 Sprint 3: Dynamic Environmental Enhancements
- [ ] **Frequency Audio Booster Profile**: Program automatic operating system volume adjustments to optimize vocal clarity during Athan streams.
- [ ] **Ambient Visual Alert Triggers**: Code soft screen-edge blinking loops to flash when automated clock events or tracking phase updates finish.



Development Roadmap: Neuro-Habit Loop for Salah
Phase 1: The Ambient Sensory Cue (Anticipatory State)

Goal: Build the local timing engine and the non-intrusive ambient glow system.

Details: Program offline prayer-time calculations that trigger a soft visual shift (the ambient glow) before the prayer starts, giving a calm, stress-free window for physical preparation.

Phase 2: The Frictionless Acknowledgment & "Bridge" Routine

Goal: Create a calm, accessible transition space.

Details: Implement large, forgiving touch targets anywhere on the screen for effortless interaction, separating cognitive intention (Niyyah) from physical movement to lower cognitive load and physical fatigue.

Phase 3: The Somatic Reward (Nervous System Closure)

Goal: Design the post-prayer decompression loop.

Details: Code the slow, graceful visual fade-out of the ambient glow paired with zero-clutter locking to trigger a parasympathetic (rest and digest) response and secure neural consolidation.

Phase 4: Local Offline State Machine & Testing

Goal: Tie the pieces together seamlessly without relying on network connectivity or intrusive metrics.

Details: Manage local states (IDLE, PACING_WINDOW, ACKNOWLEDGED, SANCTUARY) entirely on-device to ensure reliable, private, and smooth execution.
